# Privacy policy

Velocity Download Manager does not include analytics, advertising, or
telemetry. Download history, preferences, and the selected download directory
are stored locally on the user's device.

When the user starts a download, Velocity connects to the URL or peer network
the user selected. Media downloads may use the bundled yt-dlp, Deno, and FFmpeg
tools. Torrent downloads use aria2 and necessarily exchange network data with
torrent trackers and peers. Those third parties can observe the network
information normally exposed by the relevant protocol, including the user's IP
address.

The optional browser extension reads the active page only when needed to offer
or start a download. It passes the selected page URL and format to the locally
installed Velocity application through the `velocity://` protocol. It does not
send browsing history to the developer.

Velocity cannot control the privacy practices of download sources, media
platforms, trackers, peers, or operating-system services. Users should review
the policies of services they access and download only content they are
authorized to use.

Questions may be sent to the developer through the repository's GitHub issue
tracker or [Instagram](https://www.instagram.com/m_kasim2/).
