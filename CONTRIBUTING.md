# Contributing

Thank you for helping improve Velocity.

1. Open an issue for substantial changes so the approach can be discussed.
2. Fork the repository and create a focused branch.
3. Run `npm ci`, `npm run build`, and `cargo check --manifest-path src-tauri/Cargo.toml`.
4. Do not commit generated installers, bundled tool binaries, tokens, or private
   signing material.
5. Submit a pull request describing the behavior change and how it was tested.

Bug reports should include the operating system, Velocity version, download
type, relevant non-sensitive logs, and minimal reproduction steps. Remove
private URLs, cookies, tokens, and personal file paths before posting.
